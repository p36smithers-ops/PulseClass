Device setup help
WHOOP: In the WHOOP app open Device Settings → Status → enable Heart Rate Broadcast. Keep the WHOOP device worn and nearby.

Garmin watch: On supported models, open the watch settings and enable Broadcast Heart Rate (often under Health & Wellness → Wrist Heart Rate). Start broadcasting before pairing here. Not every Garmin model supports Bluetooth broadcasting.

Chest straps: Wet the electrode pads if required, wear the strap snugly, and wake it up before selecting it in the browser.

Browser: For mixed iPhone/Android classes, use the native PulseClass Student app. Browser fallback: Chrome or Edge on Android, Windows or macOS over HTTPS. iPhone/iPad Safari does not support Web Bluetooth.
